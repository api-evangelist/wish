# Wish

> Wish (ContextLogic Inc.) is a global mobile-first e-commerce marketplace. The Wish Marketplace V3 API lets merchants and ERP partners manage products, variations, orders, fulfillment, payments, penalties, tickets, ProductBoost campaigns, promotions, EU/EPR compliance, and webhook subscriptions over OAuth 2.0.

## Conventions

- Base URL: https://merchant.wish.com/api/v3/
- Auth: Authorization: Bearer <token> (OAuth 2.0 authorization code; 37 scopes)
- Errors: JSON envelope {message, code, data}; code 0 = success
- Pagination: keyset via limit + {attribute}_min/{attribute}_max; sorting via sort_by={param}.{asc|desc}
- Partial responses: fields parameter on all GET endpoints (nested via /, groups via parentheses, wildcard *)
- Rate limiting: Wish-Rate-Limit-Remaining / Wish-Rate-Limit-Reset headers; 429 on exceed
- Request tracing: Wish-Request-Id response header
- Support: partner-api@wish.com
